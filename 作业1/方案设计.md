## 1. 方法调研：解决"控制变量/混淆偏误"的方法谱系

| 方法 | 核心思想 | 与本题关系 |
|------|---------|-----------|
| **多元 OLS** | 正规方程联立求解 | 作业主线（步骤 3） |
| **FWL 残差化** | 两步残差回归，等价于多元 OLS | 作业主线（步骤 4） |
| **偏相关 / 分层回归 / ANCOVA** | 净相关的不同表述 | 作业步骤 5 的等价性验证 |
| **DAG / 后门准则**（Pearl） | 用因果图判断"该控制谁" | 创新点：讨论过度控制/碰撞变量偏误 |
| **倾向得分 + IPW**（Rosenbaum–Rubin） | 加权代替回归控制 | 扩展对比（连续处理可用广义倾向得分） |
| **Double Machine Learning**（Chernozhukov et al. 2018） | ML 拟合混杂函数 + 交叉拟合 + 残差对残差回归，Neyman 正交性保证 √n 收敛 | **核心创新点**：FWL 的现代化身 |
| **稳健推断** | HC 异方差稳健 SE、Bootstrap | 扩展：检验 t 统计量的假设敏感性 |

**关键洞察**：DML 本质上就是 FWL 的非线性推广——用任意学习器代替线性投影做残差化，再用 Neyman 正交性保证正则化偏误不进一阶项。这条线能把报告从"复现定理"升级到"定理的现代意义"。

## 2. 理论推导链条（报告第 1 部分骨架）

1. **OLS 正规方程**：$\min Q = \|y-\beta_1 x_1-\beta_2 x_2\|^2$，解得

   $$\hat\beta_1 = \frac{r_{1y}-r_{12}r_{2y}}{1-r_{12}^2}\cdot\frac{\|y\|}{\|x_1\|}$$

   （作业讲义定理 2，报告复述并解释"控制"的代数含义）

2. **FWL 定理**：$\hat\beta_1 = \dfrac{\langle M_2x_1, M_2y\rangle}{\|M_2x_1\|^2}$，其中 $M_2 = I - P_{x_2}$ 为残差化算子；关键性质 $M_2^T=M_2$、$M_2^2=M_2$、$M_2x_2=0$。

3. **偏相关系数**：

   $$r_{1y\cdot2} = \frac{r_{1y}-r_{12}r_{2y}}{\sqrt{1-r_{12}^2}\sqrt{1-r_{2y}^2}}$$

   与 $\hat\beta_1$ 只差尺度比 $\|M_2y\|/\|M_2x_1\|$（讲义注 3）。

4. **t 检验等价性**：$t^2 = (n-k)\dfrac{r_{1y\cdot Z}^2}{1-r_{1y\cdot Z}^2}$，$k=4$。

### 2.1 扩展推导：遗漏变量偏误（OVB）的解析式（创新部分自行推导）

$$\hat\beta_1^{simple} \xrightarrow{p} \beta_1 + \beta_2\frac{\mathrm{Cov}(X_1,X_2)}{\mathrm{Var}(X_1)}$$

代入本题参数：$\mathrm{Var}(X_1)=1$（$\Sigma$ 对角元），$\mathrm{Cov}(X_1,X_2)=-0.5$，$\beta_2=1.5$：

$$\text{理论渐近偏差} = 1.5\times(-0.5) = -0.75 \quad\Rightarrow\quad \hat\beta_1^{simple}\xrightarrow{p} 1.25$$

该数值将与 Monte Carlo 直方图的抽样均值直接对照——把作业要求的"定性解释偏差方向"升级为"定量预测偏差大小并被仿真证实"。

## 3. 假设清单（报告须显式声明）

| 假设 | 数学表述 | 本题中如何体现 | 违反后果 |
|------|---------|--------------|---------|
| 线性 | $E[Y\mid X_1,X_2,X_3]$ 线性 | 数据生成即线性（成立） | 系数失去解释意义 |
| 严格外生 | $E[\varepsilon\mid X]=0$ | ε 独立生成（成立）；现实中若存在遗漏混杂则失效 | 混淆偏误 |
| 无完全共线 | $\mathrm{rank}(X)=k$ | $\Sigma$ 正定（$|\rho_{ij}|<1$） | OLS 无唯一解 |
| 同方差 + 正态 | $\varepsilon\sim N(0,\sigma^2 I)$ | 生成时同方差；扩展部分故意破坏它 | 经典 t/F 失效 → 引出 HC 稳健 SE |
| 随机抽样 | i.i.d. 样本 | 成立 | — |
| 无遗漏混杂（识别假设） | 所有混杂变量可观测 | 本题 $X_2,X_3$ 已全部给定 | 条件不可识别，只能做敏感性分析 |

## 6. 代码架构（低耦合设计）

```
作业1/
├── src/
│   ├── config.py          # 唯一参数源：种子、n、μ、Σ、β_true、σ、路径（dataclass）
│   ├── datagen.py         # 数据生成 → 返回 DataFrame；save_csv 一行调用
│   ├── ols.py             # 纯 numpy 的 OLS 核（含 FWL、偏相关、t 检验），不依赖 statsmodels
│   ├── inference.py       # SE(classic/HC0/HC1)、t、p、CI —— 与 ols.py 解耦的推断层
│   ├── simulation.py      # Monte Carlo 引擎：接收任意 estimator 函数 (y,X)->beta
│   ├── advanced/
│   │   ├── ovb.py         # 渐近偏误公式 + 数值验证
│   │   └── dml.py         # 交叉拟合 DML（sklearn 学习器可插拔，默认 Lasso/RF）
│   ├── plotting.py        # 只读计算结果，产出 figures/*.html 与 *.png
│   └── main.py            # 流水线：按步骤 1→7 编排，报告数值全部落盘 results/
└── tests/
    └── test_ols.py        # 自实现 OLS vs statsmodels 数值互验（rtol=1e-10）
```

### 6.1 解耦原则

- **接口隔离**：`datagen` 不知道谁在用它；`ols.py` 不知道数据从哪来——靠 DataFrame / ndarray 接口传递
- **估计器可插拔**：`simulation.py` 接收任意估计函数 `(y, X) -> beta`，OLS、FWL、DML 共用同一 Monte Carlo 引擎，零重复代码
- **随机性单点管理**：`config.py` 统一派生子随机种子（`np.random.default_rng` 的 spawn），任何模块独立运行均可复现
- **不依赖黑盒**：核心 OLS 自实现，statsmodels 仅作互验与报告附录中的交叉验证声明
- **计算与呈现分离**：`plotting.py` 只读计算结果文件，报告数值统一落盘 `results/`（json/csv），保证"脚本复现报告全部数值"
