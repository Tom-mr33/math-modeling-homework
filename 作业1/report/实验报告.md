# 基于 FWL 定理的多元线性回归"控制变量"推证与随机仿真验证

**摘要**

本文围绕多元线性回归中"控制变量"的数学机理展开研究。针对"日均睡眠时长对期末成绩是否存在净影响"这一问题，建立了简单线性回归与多元线性回归两组对照模型，并以 Frisch–Waugh–Lovell（FWL）定理为核心完成了"控制变量"的代数推证与数值验证。

首先，按题目给定的联合正态分布（$n=60$，随机种子 2024）生成含混淆结构的数据，真实模型 $Y=60+2X_1+1.5X_2-X_3+\varepsilon$ 中睡眠的净效应真值为 $\beta_1=2$。描述统计显示睡眠与自习时长相关系数达 $-0.465$，混淆结构显著存在。随后建立简单回归模型，得到 $\hat\beta_1=0.908$（$p=0.325$），因遗漏正效应控制变量 $X_2$ 而被系统性拉低，且不显著；建立多元回归模型后 $\hat\beta_1$ 修正为 $2.094$（$p=0.034$），接近真值并在 5% 水平显著。理论方面，本文从正规方程出发推导了偏回归系数的显式表达式，证明了 FWL 定理（残差化后再回归与多元回归严格等价）、偏相关系数显式公式及 $t$ 统计量与偏相关的等价关系 $t^2=(n-k)r_{1y\cdot Z}^2/(1-r_{1y\cdot Z}^2)$。数值验证表明：FWL 两步估计与多元回归系数之差为 $1.3\times10^{-13}$（远小于题目要求的 $10^{-8}$），偏相关手算 $t$ 值与软件输出之差为 $1.4\times10^{-13}$（要求 $10^{-6}$）。进一步推导了遗漏变量偏误的解析式 $\mathrm{plim}\,\hat\beta_1^{simple}=1.45$，并被 $M=500$ 次蒙特卡洛仿真证实（抽样均值 $1.428$，$z=0.72$）。

研究表明：多元回归中"控制变量"的几何本质是对 $Y$ 与处理变量同时作正交投影、仅保留残差回归；忽略与处理负相关且对因变量正效用的混杂变量，将使估计量围绕错误中心波动，而 FWL 型残差化操作可完全消除这一混淆偏误。

**关键词**：多元线性回归；控制变量；Frisch–Waugh–Lovell 定理；偏相关系数；遗漏变量偏误；蒙特卡洛仿真

## 一、问题重述

### 1.1 问题背景

教育研究中常需回答"某项行为对学业成绩的净影响"。以睡眠为例：日均睡眠时长可能与自习时长、手机娱乐时长相互关联——睡眠多的学生往往自习更少、娱乐方式不同。若直接将成绩对睡眠做一元回归，其他变量的影响会混入睡眠的系数，产生混淆偏误（confounding bias）。如何通过多元回归"控制"这些变量、并把控制操作的数学本质说清楚，是本题的核心。

### 1.2 问题提出

给定随机仿真环境（见 5.1 节），需完成以下任务：

1. 生成仿真数据并做描述统计与相关分析，说明控制变量与关注变量之间确有共线关联；
2. 建立简单线性回归模型，分析其系数偏离真值的方向与原因；
3. 建立多元线性回归模型，估计睡眠时长的净效应并做显著性检验；
4. 从理论上推导多元回归系数的显式表达式、FWL 定理、偏相关系数及其与 $t$ 检验的等价关系；
5. 数值验证：FWL 两步估计与多元回归系数一致（误差 $<10^{-8}$）；由偏相关手算的 $t$ 统计量与软件输出一致（误差 $<10^{-6}$）；
6. 对比控制前后的系数变化，推导遗漏变量偏误的解析形式，并以蒙特卡洛仿真验证。

## 二、问题分析

本题的落脚点是一个方法论问题：**"控制变量"到底对应什么数学操作？**

分析思路如下：真值已知的仿真环境提供了"标尺"——若一个估计量正确，其抽样分布应围绕真值 $\beta_1=2$ 波动。据此设计对照实验：

- **简单回归** $Y\sim X_1$：不含任何控制。由题设，$X_1$ 与 $X_2$ 相关系数为 $-0.5$，而 $X_2$ 对 $Y$ 有正效应 $1.5$，预期简单回归系数被显著拉低——这是混淆偏误的"阳性样本"；
- **多元回归** $Y\sim X_1+X_2+X_3$：控制全部混杂。理论上其系数应为净效应的无偏估计；
- **FWL 残差化**：把 $Y$ 与 $X_1$ 分别对控制变量回归取残差后再回归。若 FWL 定理成立，其系数应与多元回归**在数值上严格相等**（而非近似），这提供了对理论的最严格检验；
- **偏相关**：两残差的相关系数，从"净关联强度"角度刻画同一对象，并与 $t$ 统计量建立解析等价。

最后，用 $M=500$ 次重复仿真观察两个估计量抽样分布的中心位置，将"控制变量消除混淆偏误"从单次样本的巧合上升为分布层面的规律。

## 三、模型假设

| 编号 | 假设 | 合理性说明 |
| ---- | ---- | ---- |
| A1 | 线性假设：$E[Y\mid X_1,X_2,X_3]=\beta_0+\beta_1X_1+\beta_2X_2+\beta_3X_3$ | 数据按该结构生成，仿真中严格成立；现实中线性近似为一阶合理刻画 |

| A3 | 无完全共线性：$\mathrm{rank}[1,X_1,X_2,X_3]=4$ | $\Sigma$ 正定（所有相关系数绝对值 $<1$），以概率 1 成立 |
| A4 | 球面扰动：$\varepsilon\sim N(0,\sigma^2I_n)$，$\sigma=5$ | 同方差且正态，保证 $t/F$ 检验精确有效 |
| A5 | 随机抽样：观测 $(Y_i,X_{1i},X_{2i},X_{3i})$ i.i.d. | 每个学生独立从总体分布抽取 |
| A6 | 无遗漏混杂：影响 $Y$ 的全部混杂变量（$X_2,X_3$）均可观测并纳入模型 | 这是净效应可识别的关键假设；若违反，只能做敏感性分析 |

## 五、模型的建立与求解

### 5.1 数据生成与预处理

**5.1.1 数据生成算法**（随机种子 2024，保证全流程可复现）

**步 1** 设定随机种子 `set.seed(2024)`。

**步 2** 生成具有混淆结构的联合分布：

$$(X_2,X_3,X_1)^T\sim N_3(\mu,\Sigma),\qquad \mu=(3,2,3)^T,\quad \Sigma=\begin{pmatrix}1.0&0.3&-0.5\\0.3&1.0&-0.2\\-0.5&-0.2&1.0\end{pmatrix}$$

$\Sigma$ 的非对角元刻画"睡眠多则自习少"（$-0.5$）、"睡眠多则手机娱乐略少"（$-0.2$）、"自习多则娱乐略多"（$0.3$）等行为关联。

**步 3** 生成误差项 $\varepsilon\sim N(0,\sigma^2)$，$\sigma=5$。

**步 4** 按真实模型生成因变量：

$$Y=60+2X_1+1.5X_2-1X_3+\varepsilon$$

真实偏回归系数 $\beta_1=2$（睡眠净效应）、$\beta_2=1.5$、$\beta_3=-1$，截距 $\beta_0=60$。

**步 5** 将 $(Y,X_1,X_2,X_3)$ 保存为 `sleep_score.csv`。

### 5.3 模型一：简单线性回归模型

#### 5.3.1 模型建立

$$Y_i=\alpha+\gamma X_{1i}+u_i,\qquad i=1,\dots,n$$

其中 $u_i$ 包含了被遗漏的 $X_2,X_3$ 的贡献，即 $u_i=1.5X_{2i}-X_{3i}+\varepsilon_i$。由 A2 仅对 $(X_1,X_2,X_3)$ 联合成立，此处 $E[u_i\mid X_{1i}]\neq 0$——**简单回归在结构上违背外生假设**。

#### 5.3.2 求解结果

最小二乘估计结果（标准误按经典公式 $\hat\sigma^2(X^TX)^{-1}$ 计算）：

| 系数 | 估计值 | 标准误 | $t$ 值 | $p$ 值 | 95% 置信区间 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 截距 | 64.747 | 2.755 | 23.50 | <0.001 | [59.23, 70.26] |
| $X_1$ | **0.908** | 0.914 | 0.993 | 0.325 | [-0.92, 2.74] |

$R^2=0.017$（图 2，`figures/fig2_simple_regression.png`）。

#### 5.3.3 结果分析

$\hat\gamma=0.908$ 远低于真值 2 且不显著（$p=0.325$），偏差方向为负，与 $r_{12}=-0.465<0$、$\beta_2=1.5>0$ 的组合完全一致：睡眠每多一小时伴随着自习约少 0.5 小时，而自习每小时贡献 1.5 分，简单回归把这部分"自习损失"错误地记在了睡眠头上。偏差的定量刻画见 5.7 节。

### 5.4 模型二：多元线性回归模型

#### 5.4.1 理论推导：最小二乘估计的显式解

为揭示"控制"的代数本质，先在单控制变量情形下推导 $\hat\beta_1$ 的显式表达式（变量已中心化，模型 $y=\beta_1x_1+\beta_2x_2+\varepsilon$ 不含截距）。

**定理 1（正规方程）** 最小化 $Q(\beta_1,\beta_2)=\|y-\beta_1x_1-\beta_2x_2\|^2$，一阶条件为

$$\frac{\partial Q}{\partial\beta_1}=-2\langle x_1,\ y-\beta_1x_1-\beta_2x_2\rangle=0,\qquad \frac{\partial Q}{\partial\beta_2}=-2\langle x_2,\ y-\beta_1x_1-\beta_2x_2\rangle=0$$

即正规方程

$$\begin{pmatrix}\|x_1\|^2&\langle x_1,x_2\rangle\\ \langle x_1,x_2\rangle&\|x_2\|^2\end{pmatrix}\begin{pmatrix}\hat\beta_1\\ \hat\beta_2\end{pmatrix}=\begin{pmatrix}\langle x_1,y\rangle\\ \langle x_2,y\rangle\end{pmatrix}$$

**定理 2（显式解）** $x_1,x_2$ 线性无关时，由 Cramer 法则：

$$\hat\beta_1=\frac{\|x_2\|^2\langle x_1,y\rangle-\langle x_1,x_2\rangle\langle x_2,y\rangle}{\|x_1\|^2\|x_2\|^2-\langle x_1,x_2\rangle^2}$$

分子分母同除 $\|x_1\|^2\|x_2\|^2$，并将 $\langle x_1,y\rangle=r_{1y}\|x_1\|\|y\|$、$\langle x_2,y\rangle=r_{2y}\|x_2\|\|y\|$、$\langle x_1,x_2\rangle=r_{12}\|x_1\|\|x_2\|$ 代入，得相关系数形式：

$$\boxed{\ \hat\beta_1=\frac{r_{1y}-r_{12}r_{2y}}{1-r_{12}^2}\cdot\frac{\|y\|}{\|x_1\|}\ }$$

**注 1（"控制"的代数含义）** 分子 $r_{1y}-r_{12}r_{2y}$ 正是从 $X_1$ 与 $Y$ 的原始相关中扣除经由 $X_2$ 重叠的部分；分母 $1-r_{12}^2$ 修正 $X_1$ 自身变异中"不被 $X_2$ 解释"的比例。故 $\hat\beta_1$ 度量的是 $X_1$ 中与 $X_2$ 正交的那部分对 $Y$ 的净效应。

#### 5.4.2 模型建立与求解

$$Y_i=\beta_0+\beta_1X_{1i}+\beta_2X_{2i}+\beta_3X_{3i}+\varepsilon_i$$

最小二乘结果：

| 系数 | 估计值 | 标准误 | $t$ 值 | $p$ 值 | 95% 置信区间 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 截距 | 56.551 | 4.537 | 12.46 | <0.001 | [47.46, 65.64] |
| $X_1$ | **2.094** | 0.964 | 2.172 | 0.034 | [0.16, 4.02] |
| $X_2$ | 2.460 | 0.756 | 3.253 | 0.002 | [0.95, 3.97] |
| $X_3$ | -1.155 | 0.765 | -1.508 | 0.137 | [-2.69, 0.38] |

调整 $R^2=0.141$。

#### 5.4.3 结果分析

- $\hat\beta_1=2.094$：**保持 $X_2,X_3$ 不变，睡眠每增加 1 小时，成绩平均提高约 2.09 分**，与真值 2 接近（相差 0.094，仅为 0.1 个标准误）；
- 假设检验 $H_0:\beta_1=0$：$t=2.172$，$p=0.034<0.05$，在 5% 水平拒绝原假设，睡眠的净效应显著为正；
- $\hat\beta_2=2.460$ 接近真值 1.5 且显著；$\hat\beta_3=-1.155$ 接近真值 $-1$ 但 $p=0.137$ 不显著——$n=60$ 下小效应的检验功效有限，属抽样波动而非方法缺陷。

### 5.5 FWL 定理及其数值验证

#### 5.5.1 定理推导

**定义（残差化算子）** $M_2=I-P_{x_2}$，其中 $P_{x_2}=x_2(x_2^Tx_2)^{-1}x_2^T$ 是向 $\mathrm{span}(x_2)$ 的投影矩阵。$M_2u$ 即 $u$ 对 $x_2$ 回归后的残差向量。

**引理（投影矩阵性质）** $M_2^T=M_2$（对称），$M_2^2=M_2$（幂等），$M_2x_2=0$。

**定理 3（FWL 定理，单控制变量情形）** 模型 $y=\beta_1x_1+\beta_2x_2+\varepsilon$ 的 $\hat\beta_1$ 等于 $M_2y$ 对 $M_2x_1$ 无截距回归的斜率：

$$\hat\beta_1=\frac{\langle M_2x_1,\ M_2y\rangle}{\|M_2x_1\|^2}$$

**证明** 由内积的展开性：

$$\langle M_2x_1,\ M_2y\rangle=x_1^TM_2^TM_2y=x_1^TM_2y=\langle x_1,y\rangle-\frac{\langle x_1,x_2\rangle\langle x_2,y\rangle}{\|x_2\|^2}$$

$$\|M_2x_1\|^2=\langle x_1,x_1\rangle-\frac{\langle x_1,x_2\rangle^2}{\|x_2\|^2}$$

两者之比恰为定理 2 中 Cramer 法则解出的 $\hat\beta_1$。$\blacksquare$

**注 2（几何解释）** 残差化即正交投影：$M_2y$ 与 $M_2x_1$ 分别是 $y$、$x_1$ 落在 $\mathrm{span}(x_2)$ 正交补上的分量（图 3，`figures/fig7_fwl_geometry.png`）。FWL 说明"控制 $X_2$"的几何操作是把两个向量都投影到与 $X_2$ 垂直的方向上，再量它们之间的关系——这就是"保持 $X_2$ 不变"的严格数学含义。

**推广（多控制变量）** $Z=(x_2,\dots,x_k)\in\mathbb{R}^{n\times(k-1)}$，$M=I-Z(Z^TZ)^{-1}Z^T$，则

$$\hat\beta_1=\frac{\langle Mx_1,\ My\rangle}{\|Mx_1\|^2}$$

即把 $Y$ 与 $X_1$ 分别对全部控制变量回归取残差再做简单回归。

#### 5.5.2 数值验证

按推广形式执行两步法：$e_Y=My$，$e_{X_1}=Mx_1$（$M$ 对 $(X_2,X_3)$ 含截距残差化），以 $e_Y$ 对 $e_{X_1}$ 无截距回归得 $\hat\beta_1^{FWL}$。

| 量 | 数值 |
| ---- | ---- |
| $\hat\beta_1^{FWL}$ | 2.093561713922 |
| $\hat\beta_1^{multi}$（多元回归） | 2.093561713922 |
| 绝对差 | $1.3\times10^{-13}$ |

**结论**：两者之差 $1.3\times10^{-13}$，远小于题目要求的 $10^{-8}$（严格来说差值仅来自浮点舍入，二者在代数上恒等）——与 FWL 定理的结论完全一致。图 4（`figures/fig3_added_variable.png`）的 added-variable plot 给出可视化证据：残差散点的拟合斜率正是 $\hat\beta_1$。

### 5.6 偏相关系数与 $t$ 检验的等价性验证

#### 5.6.1 理论推导

**定义（偏相关系数）** 控制 $X_2$ 后，$X_1$ 与 $Y$ 的偏相关系数为两残差的相关系数：

$$r_{1y\cdot2}=\frac{\langle M_2x_1,\ M_2y\rangle}{\|M_2x_1\|\ \|M_2y\|}$$

**命题 1（显式公式）** 由 FWL 定理的证明，$\langle M_2x_1,M_2y\rangle=\|x_1\|\|y\|(r_{1y}-r_{12}r_{2y})$，$\|M_2x_1\|^2=\|x_1\|^2(1-r_{12}^2)$，$\|M_2y\|^2=\|y\|^2(1-r_{2y}^2)$，代入定义得

$$r_{1y\cdot2}=\frac{r_{1y}-r_{12}r_{2y}}{\sqrt{1-r_{12}^2}\ \sqrt{1-r_{2y}^2}}$$

**命题 2（与回归系数的关系）** 比较定理 2 与命题 1：

$$\hat\beta_1=r_{1y\cdot2}\cdot\frac{\|M_2y\|}{\|M_2x_1\|}$$

即偏回归系数 = 偏相关 × 残差尺度比，与简单回归"斜率 = 相关系数 × 标准差之比"的结构完全平行。

**命题 3（$t$ 统计量的偏相关表示）** 正态误差下（A4），检验 $H_0:\beta_1=0$ 的统计量满足

$$t^2=(n-k)\cdot\frac{r_{1y\cdot Z}^2}{1-r_{1y\cdot Z}^2},\qquad k=4$$

即 $\beta_1$ 的显著性**完全由净相关决定**。

#### 5.6.2 数值验证

由两残差直接计算偏相关，并按命题 3 手算 $t$：

| 量 | 数值 |
| ---- | ---- |
| $r_{1y\cdot23}$ | 0.278753 |
| 手算 $t=\sqrt{56\times\dfrac{0.278753^2}{1-0.278753^2}}$ | 2.172093 |
| 软件 $t$（多元回归输出） | 2.172093 |
| 绝对差 | $1.4\times10^{-13}$ |

**结论**：差值 $1.4\times10^{-13}$，远小于要求的 $10^{-6}$，命题 3 得到精确验证——$t$ 检验本质上只依赖净相关。

### 5.7 遗漏变量偏误的解析推导与蒙特卡洛验证

#### 5.7.1 偏误的解析形式

简单回归同时遗漏 $X_2$ 与 $X_3$。由 FWL 视角，$\hat\beta_1^{simple}=\dfrac{\langle \tilde x_1,\ y\rangle}{\|\tilde x_1\|^2}$（$\tilde x_1=x_1-\bar x_1$），代入 $y=\beta_1x_1+\beta_2x_2+\beta_3x_3+\varepsilon$ 并取概率极限，利用总体矩可得

$$\mathrm{plim}\ \hat\beta_1^{simple}=\beta_1+\beta_2\frac{\mathrm{Cov}(X_1,X_2)}{\mathrm{Var}(X_1)}+\beta_3\frac{\mathrm{Cov}(X_1,X_3)}{\mathrm{Var}(X_1)}$$

代入总体参数（$\mathrm{Var}(X_1)=1$，$\mathrm{Cov}(X_1,X_2)=-0.5$，$\mathrm{Cov}(X_1,X_3)=-0.2$）：

$$\mathrm{plim}\ \hat\beta_1^{simple}=2+1.5\times(-0.5)+(-1)\times(-0.2)=\mathbf{1.45}$$

$X_2$ 项（$-0.75$）是偏误主源；$X_3$ 项（$+0.2$）部分抵消。若已控制 $X_2$ 而仅遗漏 $X_3$，则偏误须用条件协方差计算：

$$\text{bias}=\beta_3\cdot\frac{\mathrm{Cov}(X_1,X_3\mid X_2)}{\mathrm{Var}(X_3\mid X_2)}=(-1)\times\frac{-0.2-(-0.5)(0.3)}{1-0.3^2}=+0.055$$

给定 $X_2$ 后 $X_1$ 与 $X_3$ 的条件关联远弱于边际关联（$-0.055$ vs $-0.2$），说明大部分混淆已被 $X_2$ 吸收。

#### 5.7.2 蒙特卡洛验证（$M=500$）

将数据生成算法独立重复 500 次，分别记录 $\hat\beta_1^{simple}$ 与 $\hat\beta_1^{multi}$，得抽样分布（图 5，`figures/fig5_mc_histogram.png`）：

| 估计量 | 抽样均值 | MC 标准误 | 理论中心 |
| ---- | ---- | ---- | ---- |
| $\hat\beta_1^{simple}$ | 1.4281 | 0.0303 | 1.45（OVB 渐近值） |
| $\hat\beta_1^{multi}$ | 1.9678 | 0.0348 | 2.00（真值） |

$\hat\beta_1^{simple}$ 的均值与渐近预测 1.45 之差的 $z$ 值为 0.72；$\hat\beta_1^{multi}$ 与真值 2 之差的 $z$ 值为 0.92，均在 3 个 MC 标准误内一致。

**结论**：多元回归估计量围绕真值 2 波动，简单回归估计量围绕**系统性偏离真值的 1.45** 波动——仿真在分布层面证实了"控制变量消除混淆偏误"。

#### 5.7.3 控制前后对比与讨论

| | 简单回归 | 多元回归 | FWL |
| ---- | ---- | ---- | ---- |
| $\hat\beta_1$ | 0.908 | 2.094 | 2.094（代数恒等） |
| 标准误 | 0.914 | 0.964 | — |
| $p$ 值 | 0.325 | 0.034 | — |

控制使系数从 0.908 修正至 2.094（变化 $+1.186$），方向未变但从不显著变为 5% 水平显著（图 6，`figures/fig4_coef_comparison.png`）。偏差来源是 $X_1$ 与 $X_2$ 的负相关（$-0.465$）把 $X_2$ 的正效应"泄漏"进简单回归系数；样本层面该泄漏量为 $\hat\beta_2\cdot\dfrac{\widehat{\mathrm{Cov}}(X_1,X_2)}{\widehat{\mathrm{Var}}(X_1)}\approx-0.90$，与观测变化量级一致。

**方法局限**：控制变量只能消除**可观测**混杂（假设 A6）；相关关系不等于因果关系，"保持 $X_2,X_3$ 不变"是统计条件而非干预；若存在未观测混杂（违反 A6），净效应不可点识别，只能做敏感性分析。

## 六、模型的评价

### 6.1 模型的优点

1. **理论闭环**：从正规方程 → 显式解 → FWL 定理 → 偏相关 → $t$ 等价性形成完整推导链，数值验证达到机器精度（$10^{-13}$ 量级），远优于题目要求（$10^{-8}$ / $10^{-6}$）；
2. **真值标尺**：仿真环境真值已知，使"控制是否有效"可以被定量评判——简单回归的抽样分布中心被解析预测（1.45）并被仿真证实，结论不依赖单次抽样运气；
3. **可复现性**：全部结果由种子 2024 一键复现，附自动化验收脚本（9 项检查全部通过）。

### 6.2 模型的缺点

1. 线性与正态假设均为仿真内生的便利设定，现实数据（如非线性效应、厚尾分布）下线性 OLS 的净效应解释力会下降；
2. $n=60$ 下弱效应（如 $X_3$）检验功效不足，$p$ 值结论对抽样波动敏感；
3. 模型只处理"可观测混杂"；对未观测混杂的稳健性未量化。

### 6.3 模型的改进方向

FWL 的"残差化"思想可以推广：将两步回归中的线性拟合替换为机器学习模型并配合交叉拟合（Double/Debiased Machine Learning，2018），可处理控制变量以非线性形式进入方程的情形；在此基础上还可对"存在未观测混杂"构造敏感性分析框架（Cinelli–Hazlett，2020）。此为后续工作。
