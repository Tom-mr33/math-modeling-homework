## (1) 问题与模型

**研究问题**：学生日均睡眠时长 $X_1$ 对期末平均成绩 $Y$ 是否有净影响？由于睡眠与自习时长 $X_2$、手机娱乐时长 $X_3$ 相互关联，直接做简单回归会把其他变量的影响混入睡眠的系数。需在控制 $X_2,X_3$ 的条件下识别净效应，并用 Frisch–Waugh–Lovell (FWL) 定理验证。

**变量角色**（$n=60$）：

| 变量 | 含义 | 角色 |
| ---- | ---- | ---- |
| $Y$ | 期末平均成绩 | 因变量 |
| $X_1$ | 日均睡眠时长（小时） | 关注的自变量 |
| $X_2$ | 日均自习时长（小时） | 控制变量 |
| $X_3$ | 日均手机娱乐时长（小时） | 控制变量 |

**总体模型**：

$$Y = 60 + 2X_1 + 1.5X_2 - 1X_3 + \varepsilon,\qquad \varepsilon\sim N(0,5^2)$$

真实偏回归系数 $\beta_1=2$（睡眠净效应）、$\beta_2=1.5$、$\beta_3=-1$，截距 $\beta_0=60$。

**假设清单**（显式声明）：

| 假设 | 数学表述 | 本题中如何体现 | 违反后果 |
| ---- | ---- | ---- | ---- |
| 线性 | $E[Y\mid X_1,X_2,X_3]$ 线性 | 数据生成即线性（成立） | 系数失去解释意义 |
| 严格外生 | $E[\varepsilon\mid X]=0$ | $\varepsilon$ 独立生成（成立）；现实中若有遗漏混杂则失效 | 混淆偏误 |
| 无完全共线 | $\mathrm{rank}(X)=k$ | $\Sigma$ 正定（$|\rho_{ij}|<1$） | OLS 无唯一解 |
| 同方差+正态 | $\varepsilon\sim N(0,\sigma^2I)$ | 生成时同方差；扩展 4.4 故意破坏它 | 经典 t 失效 → HC 稳健 SE |
| 随机抽样 | i.i.d. | 成立 | — |
| 无遗漏混杂 | 所有混杂可观测 | 本题 $X_2,X_3$ 全部给定 | 不可识别，只能敏感性分析（见 §6 扩展） |

## (2) 数据生成

按习题算法（随机种子 `2024`）：

- 步 2：$(X_2,X_3,X_1)^T\sim N_3(\mu,\Sigma)$，$\mu=(3,2,3)^T$，$\Sigma=\begin{pmatrix}1.0&0.3&-0.5\\0.3&1.0&-0.2\\-0.5&-0.2&1.0\end{pmatrix}$
- 步 3：$\varepsilon\sim N(0,5^2)$
- 步 4：$Y=60+2X_1+1.5X_2-1X_3+\varepsilon$
- 步 5：保存 `data/sleep_score.csv`

**描述统计**：

| 变量 | 均值 | 标准差 |
| ---- | ---- | ---- |
| $Y$ | 67.3617 | 6.2591 |
| $X_1$ | 2.8801 | 0.8911 |
| $X_2$ | 2.8885 | 1.1440 |
| $X_3$ | 2.0137 | 1.0241 |

**相关矩阵**（图 `figures/fig1_corr_heatmap.png`）：

|  | Y | X1 | X2 | X3 |
| ---- | ---- | ---- | ---- | ---- |
| **Y** | 1.000 | 0.129 | 0.265 | -0.143 |
| **X1** | 0.129 | 1.000 | **-0.465** | **-0.213** |
| **X2** | 0.265 | -0.465 | 1.000 | 0.243 |
| **X3** | -0.143 | -0.213 | 0.243 | 1.000 |

$r_{12}=-0.465$（睡眠与自习显著负相关）、$r_{13}=-0.213$（睡眠与手机负相关），符号与 $\Sigma$ 设定一致，控制变量确有共线关联——这正是"控制"必要性的来源。

## (3) 简单回归结果（不控制）

$Y\sim X_1$（含截距），图 `fig2_simple_regression.png`：

| 系数 | 估计 | SE | t | p | 95% CI |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 截距 | 64.747 | 2.755 | 23.50 | <0.001 | [59.23, 70.26] |
| $X_1$ | **0.908** | 0.914 | 0.993 | 0.325 | [-0.92, 2.74] |

$R^2=0.017$。$\hat\beta_1^{simple}=0.908$ 远低于真值 2 且不显著。

**偏差方向解释**：$X_1$ 与 $X_2$ 负相关（$r_{12}=-0.465$），而 $X_2$ 对 $Y$ 有正效应（$\beta_2=1.5$）。睡眠多的学生倾向自习少，简单回归把"自习少带来的成绩损失"记在了"睡眠"头上，把系数向下拉。定量地，样本 OVB 分解为 $X_2$ 项 $-0.896$ 与 $X_3$ 项 $+0.245$，合计 $-0.650$，与观测到的差距 $2.094-0.908\approx1.19$ 量级一致（有限样本下部分被抽样噪声抵消）。

## (4) 多元回归结果（控制）

$Y\sim X_1+X_2+X_3$：

| 系数 | 估计 | SE | t | p | 95% CI |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 截距 | 56.551 | 4.537 | 12.46 | <0.001 | [47.46, 65.64] |
| $X_1$ | **2.094** | 0.964 | 2.172 | 0.034 | [0.16, 4.02] |
| $X_2$ | 2.460 | 0.756 | 3.253 | 0.002 | [0.95, 3.97] |
| $X_3$ | -1.155 | 0.765 | -1.508 | 0.137 | [-2.69, 0.38] |

调整 $R^2=0.141$。

**解释与检验**：$\hat\beta_1=2.094$——保持 $X_2,X_3$ 不变，睡眠每增加 1 小时，期末成绩平均提高约 **2.09 分**，接近真值 2。检验 $H_0:\beta_1=0$：$t=2.172$，$p=0.034<0.05$，在 5% 水平拒绝原假设，睡眠的净效应显著。注意 $\hat\beta_3=-1.155$ 与真值 $-1$ 也接近，但 $p=0.137$ 不显著——$n=60$ 下功效有限，与 $X_2$ 的系数（真值 1.5，估计 2.46，$p=0.002$）相比，效应大小的信噪比决定了检验结果。

## (5) FWL 验证

**残差化步骤**：令 $M$ 为对 $(X_2,X_3)$（含截距）的残差化算子，$e_Y=My$，$e_{X_1}=Mx_1$；用 $e_Y$ 对 $e_{X_1}$ 做无截距回归：

$$\hat\beta_1^{FWL}=\frac{\langle e_{X_1},e_Y\rangle}{\|e_{X_1}\|^2}$$

**数值对比**：

| 量 | 数值 |
| ---- | ---- |
| $\hat\beta_1^{FWL}$ | 2.093561713922 |
| $\hat\beta_1^{multiple}$ | 2.093561713922 |
| $\|\Delta\|$ | **1.27e-13**（要求 < 1e-8 ✓） |

这正是 FWL 定理的结论：控制 $X_2,X_3$ 的数学操作等价于把 $Y$ 和 $X_1$ 中能被它们线性解释的部分都减掉，只保留"净"的部分做回归。图 `fig3_added_variable.png`（added-variable plot）给出几何直观：残差散点的拟合斜率就是 $\hat\beta_1$。

## (6) 偏相关验证

控制 $(X_2,X_3)$ 后 $X_1$ 与 $Y$ 的偏相关（两残差的相关系数）：

$$r_{1y\cdot23}=0.278753$$

手算 t 值（$k=4$）：

$$t^2=(n-k)\frac{r_{1y\cdot23}^2}{1-r_{1y\cdot23}^2}\ \Rightarrow\ t=2.172093$$

| 量 | 数值 |
| ---- | ---- |
| 手算 t | 2.172093 |
| 软件 t（多元回归输出） | 2.172093 |
| $\|\Delta\|$ | **1.44e-13**（要求 < 1e-6 ✓） |

t 检验只依赖净相关：$\beta_1$ 的显著性完全由 $r_{1y\cdot23}$ 决定。

## (7) 讨论

**(a) 控制前后系数变化**（图 `fig4_coef_comparison.png`）：

| | 简单回归 | 多元回归 | FWL |
| ---- | ---- | ---- | ---- |
| $\hat\beta_1$ | 0.908 | 2.094 | 2.094（数值恒等） |
| SE | 0.914 | 0.964 | — |
| p | 0.325 | 0.034 | — |

控制使系数从 0.908 修正到 2.094（+1.186），方向未变（仍为正），但从不显著变为 5% 水平显著。偏差来源：$X_1$ 与 $X_2$ 的负相关（$-0.465$）把 $X_2$ 的正效应（1.5）"泄漏"进了简单回归系数。

**(b) 遗漏变量的偏误方向（解析推导 + 仿真验证）**：简单回归同时遗漏 $X_2,X_3$，渐近偏误为

$$\mathrm{plim}\ \hat\beta_1^{simple}=\beta_1+\beta_2\frac{\sigma_{12}}{\sigma_{11}}+\beta_3\frac{\sigma_{13}}{\sigma_{11}}=2+1.5\times(-0.5)+(-1)\times(-0.2)=\mathbf{1.45}$$

$X_2$ 项（$-0.75$）是主源，$X_3$ 项（$+0.2$）部分抵消。Monte Carlo（$M=500$，图 `fig5_mc_histogram.png`）：$\hat\beta_1^{simple}$ 抽样均值 $1.428\pm0.030$（MC-SE），与理论 1.45 的 z=0.72，一致 ✓；$\hat\beta_1^{multiple}$ 均值 $1.968\pm0.035$，围绕真值 2 波动（z=0.92）✓。

> 方法论备注：推导最初只计 $X_2$ 项得 1.25，被仿真以 z≈6 否决后补上 $X_3$ 项——解析与仿真互验正是本作业方法论的核心。

**(c) 若遗漏 $X_3$（手机时长）这类混淆变量对 $\hat\beta_1$ 的偏误**：$X_3$ 与 $X_1$ 负相关（$-0.213$）且对 $Y$ 有负效应（$-1$），遗漏它使 $\hat\beta_1$ 产生 $(-1)\times(-0.213)/1=+0.213$ 量级的向上偏误。更一般地，遗漏 $X_j$ 的偏误方向由 $\beta_j\cdot\sigma_{1j}/\sigma_{11}$ 的符号决定：与处理正相关且对 $Y$ 正效用的混杂把系数往上推，反之往下拉。本例中若只控制 $X_2$ 而漏 $X_3$，$X_3$ 项的向上偏误（$+0.2$）恰好部分抵消 $X_2$ 项的向下偏误（$-0.75$）——这是"控制变量要控制全"的直观例证，也说明逐个解读偏误方向必须看全部分配。

**(d) 方法局限（相关 ≠ 因果）**：
- 控制变量只能消除**可观测**混杂。未观测混杂是否足以颠覆结论，可定量评估：CH2020 敏感性分析（图 `fig6_sensitivity_contour.png`）显示 $t=2.17$ 仅略高于临界值 2.00，**稳健值 RV=0.020**——一个与 $X_1$、$Y$ 偏 $R^2$ 都只有约 2% 的隐藏混杂即可翻转显著性。该恒等式在我们"删去 $X_3$ 再找回"的实验中以 $3.2\times10^{-13}$ 的误差精确复现。
- 系数解释依赖线性与外生假设；"保持 $X_2,X_3$ 不变"在观测数据中只是统计意义上的条件，不构成干预。
- 睡眠-成绩关系若真做因果推断，需要随机化或更强的识别假设。

**(e) 前沿方法扩展综述（2018→2021 谱系）**：FWL（1933/1963）→ DML（Chernozhukov et al. 2018：ML 烦恼项 + 交叉拟合 + Neyman 正交）→ CH2020 敏感性分析（JRSS-B）→ DR-learner（Kennedy 2020）/ Causal Forest（Athey–Wager 2019）→ R-learner（Nie–Wager 2021）→ conformal 因果推断（Lei–Candès 2021）。我们在右偏混淆场景（$X_2$ 右偏、$Y=60+2X_1+1.5X_2^2-X_3+\varepsilon$）做了估计器竞赛（图 `fig8_race.png`，$n=600$、$M=60$）：

| 方法 | MC 均值 | MC-SE | 偏差 |
| ---- | ---- | ---- | ---- |
| 线性 OLS | 2.758 | 0.050 | +0.758 |
| DML-Lasso（线性烦恼项） | 2.834 | 0.059 | +0.834 |
| **DML-RF（非参烦恼项）** | **1.817** | 0.041 | **-0.183** |

线性方法族聚在渐近偏误参考值 2.75（N=30 万仿真确定）附近，灵活烦恼项把偏误压到 $-0.18$。两个重要发现：①**联合正态下线性 OLS 对 $\beta_1$ 天然无偏**（任何 $g(W)$ 与 $X_1$ 残差正交），必须破坏正态性竞赛才有区分度；②常数效应下 R-learner 与 DR-learner 的点估计与 DML-RF 数学恒等（同一 Robinson 闭式），它们的差异在异质效应估计与推断。单次展示表中 CausalForest 给出 2.45±0.03。$n=60$ 时 ML 烦恼项自身方差过大（DML 小样本局限），故竞赛在 $n=600$ 下进行。

**(f) 个体层面推断**：DML 只有渐近区间；分裂 conformal（Lei–Candès 2021）给出分布无关的有限样本区间，200 次重复的经验覆盖 **93.5%** ≥ 名义 90%（图 `fig9_conformal.png`）。

## (8) 附录

**A. 代码结构**（低耦合设计）：

```
src/
├── config.py      # 唯一参数源：种子流 spawn 派生，pathlib 全解析
├── datagen.py     # 数据生成（线性主组 / 右偏非线性实验组）
├── ols.py         # 纯 numpy：OLS / FWL / 偏相关 / t（statsmodels 仅互验）
├── inference.py   # SE(经典/HC1)、t、p、CI —— 与估计解耦的推断层
├── simulation.py  # MC 引擎：接收任意 (df)->beta1 估计函数
├── advanced/      # ovb / sensitivity(CH2020) / dml / meta_learners / conformal / race
├── plotting.py    # 9 张图，只读 results/，plotly + matplotlib 双输出
├── qa_check.py    # 交付验收 9 项
└── main.py        # 步骤 1–6 流水线
tests/test_ols.py  # 7 项互验测试（vs statsmodels rtol=1e-10）
```

解耦原则：datagen 不知道消费者；simulation 接收任意估计函数（OLS/FWL/DML 共用同一 MC 引擎）；plotting 只读落盘结果；随机性由 config 单点管理，任何模块独立运行可复现。

**B. 数据文件**：`data/sleep_score.csv`，60 行 × 4 列（Y,X1,X2,X3），种子 2024 唯一确定。

**C. 复现命令**：

```bash
python src/main.py                  # 步骤 1–6
python src/advanced/ovb.py          # MC M=500 + OVB 验证
python src/advanced/sensitivity.py  # CH2020
python src/advanced/race.py         # 估计器竞赛 (n=600, M=60)
python src/advanced/conformal.py    # conformal 覆盖率
python src/plotting.py              # 9 张图
python src/qa_check.py              # 验收 9/9
python -m pytest tests/ -v          # 7 项测试
```

**D. 依赖**：numpy / pandas / scipy / statsmodels / scikit-learn / plotly / matplotlib / econml（可选，缺失自动降级）。
